# St-Patrick-s-day

An addictive, festive take on the classical **Snake** arcade game built for St Patrick's Day.

## Game: Shamrock Snake 🍀

Guide your snake through the parade route, collect glittering gold pots and shamrocks, and avoid cursed clover traps as the speed ramps up with your score.

### Features
- Classic Snake gameplay with smooth controls (Arrow keys + WASD).
- St Patrick's Day visual theme.
- Progressive difficulty and speed scaling.
- Multiple collectible types:
  - **Gold pot**: +10 points
  - **Shamrock**: +4 points
  - **Red trap clover**: instant game over
- Pause/resume with space bar.
- Persistent high score in browser local storage.

## Run locally
Because this is a static browser game, you can run it with any static file server.

```bash
python3 -m http.server 8000
```

Then open: `http://localhost:8000`
